Figure 3: Flowchart - How a Sale Works

flowchart TD
  A([Start]) --> B[/User selects a product/]
  B --> C[/User enters quantity/]
  C --> D[System checks available stock]
  D --> E{Stock ≥ quantity?}
  E -- Yes --> F[Save the sale and sale items]
  F --> G[Reduce product stock]
  G --> H[Show success message]
  H --> Z([End])
  E -- No --> I[Show 'Insufficient stock']
  I --> Z

Figure 4: UML Class Diagram

classDiagram
  direction LR
  class Product {
    -int productId
    -String name
    -String sku
    -String category
    -double costPrice
    -double sellingPrice
    -int quantityInStock
    -int reorderLevel
    +isLowStock() boolean
    +getStockValue() double
    +reduceStock(int qty) void
  }
  class Sale {
    -int saleId
    -Date saleDate
    -double totalAmount
    -String paymentMethod
    +calculateTotal() double
  }
  class SaleItem {
    -int saleItemId
    -int quantitySold
    -double unitPrice
    +getSubtotal() double
  }
  class ProductService {
    +addProduct(Product p) void
    +updateProduct(Product p) void
    +deleteProduct(int id) void
    +searchProducts(String keyword) List~Product~
  }
  class SalesService {
    +recordSale(List~SaleItem~ items, String paymentMethod) Sale
    +checkStock(int productId, int qty) boolean
  }
  class ReportService {
    +getLowStockItems() List~Product~
    +calculateInventoryValue() double
    +getDashboardSummary() Map
  }
  Sale "1" *-- "1..*" SaleItem : contains
  Product "1" --> "0..*" SaleItem : sold as
  ProductService ..> Product
  SalesService ..> Sale
  SalesService ..> SaleItem
  SalesService ..> Product
  ReportService ..> Product

Figure 5: UML Sequence Diagram - Record Sale

sequenceDiagram
  actor U as Shop User
  participant P as Record Sale Page
  participant S as SalesService
  participant D as Database
  U->>P: Select product and enter quantity
  P->>S: recordSale(productId, qty, paymentMethod)
  S->>D: getStock(productId)
  D-->>S: quantityInStock
  alt stock ≥ quantity
    S->>D: saveSale() and saveSaleItem()
    S->>D: updateStock(productId, stock - qty)
    D-->>S: saved
    S-->>P: success
    P-->>U: Sale recorded successfully
  else stock too low
    S-->>P: error
    P-->>U: Insufficient stock
  end
